Browser Network Toolkit

A few network tools that run in the page. Ping is timed from your browser as an HTTPS round-trip (not ICMP), once every 500 ms. Traceroute, DNS, and the web / TLS probe can't run in a browser directly, so they execute on a Globalping probe — which is also what lets DNS query any resolver and fetches a live host's certificate. The TLS certificate card also parses a cert file you already have, entirely in the page and offline. Ping and traceroute results export to CSV.

Browser Network Toolkit

Times an HTTPS request to a regional endpoint from your browser, once every 500 ms. This is not ICMP — a browser can't send a real ping — so each value includes DNS/TLS/HTTP overhead, and a request that errors or doesn't answer within 2 s is counted as a lost packet.

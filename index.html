Browser Network Toolkit

A few network tools that run in the page. Ping is timed from your browser as an HTTPS round-trip (not ICMP), once every 500 ms. Traceroute and DNS can't run in a browser directly, so they execute on a Globalping probe — which is also what lets DNS query any resolver you pick. Ping and traceroute results export to CSV.

Ping

HTTPS round-trip time to a cloud region. A request that errors or doesn't answer within 2 s counts as a lost packet.
